# The Bandit Challenge

For any beginner who discovers OverTheWire, the first set of wargames (*why are they called that?!*) you must surmount is the Bandit challenge.
This first set of challenges is designed to train learners on the basics of the linux operating system which can be quite daunting for beginners.

As for me, I recently fell in love with the world of cybersecurity and quickly became fascinated with Linux - an operating system with no graphical user interface that promises its power users 'freedom'. 

With no GUI, users of Linux have to learn how to get comfortable using the command line, navigate through complex file systems, read hidden and encoded files and think logically like a cybersecurity specialist.

OTW's Bandit Challenge is a free Catch the Flag game that is designed to help beginners tackle linux from the basics with a very simple goal to find the passwords hidden in files from one level to the next. Sounds easy? It is definitely not!

## My Mission
My mission which I have chosen to accept is to not just conquer these challenges but to truly understand what they are trying to teach. This journal will detail my learnings and a breakdown of the concepts taught. 

Happy learning and stay curious!
